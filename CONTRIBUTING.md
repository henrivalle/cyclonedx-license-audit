# Contributing / Como contribuir

Choose a [beginner task](https://github.com/henrivalle/cyclonedx-license-audit/contribute). Use synthetic inputs and include the command, expected output, and exit status in the pull request. Contributions in English and Portuguese are welcome.

Escolha uma [tarefa para iniciantes](https://github.com/henrivalle/cyclonedx-license-audit/contribute). Use entradas inventadas e inclua o comando, a saída esperada e o código de saída no pull request.

```bash
python3 -m unittest discover -s tests -v
```
